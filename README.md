

## 模块化选择性安装脚本


一键安装 Docker 和多种常用服务，支持模块化扩展，自动记录凭证。

## 功能

- ✅ 自动安装 Docker + Docker Compose
- ✅ 支持多应用独立/批量安装
- ✅ 端口检测与开放 (iptables)
- ✅ 自动记录用户名/密码/访问地址
- ✅ 模块化设计，易于扩展
